# SCPG — スーパー計算練習ゲーム

[アプリを開く](https://yosssie.github.io/scpg/)

小学生向けの計算練習アプリです。ブラウザ上で動作し、インストールは不要です。

## できること

- **練習**：1問ずつ答え合わせ。間違えた問題は、最後にまとめて復習できます。
- **テスト**：選んだ問題数に答えたあと、結果と問題ごとの正誤を確認できます。
- **計算カード**：足し算・引き算のカードを順番またはランダムに解けます。ひとりで挑戦するモードと、大人が正誤を判定するモードを選べます。完走時間と自己ベストも記録します。

練習・テストでは、足し算または引き算、10問または20問を選べます。難しさは「1桁で答えも1桁」「1桁同士で答えは2桁まで」「2桁の計算」から設定できます。答えは入力欄、画面の数字キー、または音声で入力できます。音声入力では「答えだけ」か「式と答え」を選べます。音声入力は対応ブラウザで利用できます。

画面のふりがな表示は切り替えられます。正解数や学習日数などの記録は、利用中のブラウザに保存されます。

## 計算カードの編集

カードの問題は `table.csv` で管理しています。列は `order,set,a,operation,b` です。`set` は `たしざん①`、`ひきざん①`、`たしざん②`、`ひきざん②` のいずれか、`operation` は `+` または `-` を指定します。

GitHub PagesなどWebサーバー上では `table.csv` を自動で読み込みます。`index.html` を直接開く場合は、カードを始めるときにファイル選択画面が出るので、同じフォルダの `table.csv` を選んでください。

## ファイル

- `index.html`：画面の構成
- `styles.css`：画面デザイン
- `app.js`：問題生成、ゲーム進行、音声入力、記録
- `table.csv`：計算カードの問題
- `ruby-dictionary.js`：漢字とふりがなの対応表
- `writing.js`：ふりがなの表示処理
