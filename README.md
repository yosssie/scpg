# SCPG — スーパー計算練習ゲーム

ブラウザだけで動く、小学生向けの計算練習アプリです。`index.html` をChromeで開くと使えます。

## 現在の機能

- 足し算・引き算（1桁、答えも1桁）の設定
- 練習モード、テストモード、計算カードモード
- 手入力とChrome系ブラウザの音声入力
- 間違い問題の復習
- 計算カード完走タイムと端末内の自己ベスト保存

計算カードは `table.csv` の `order,set,a,operation,b` を読み込みます。GitHub PagesなどWebサーバー上では自動で読み込みます。`index.html` を直接開いた場合は、カードモードを選ぶときにファイル選択画面が出るので、同じフォルダの `table.csv` を選んでください。

計算の種類は `app.js` の `operationInfo` に集約しています。掛け算・割り算を追加する際は、表示設定と問題生成規則を追加します。
